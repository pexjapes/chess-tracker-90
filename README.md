# Chess Tracker 90

PWA-заготовка личного шахматного трекера для профиля DIRMEN.

## Что работает
- Чтение публичного Rapid-рейтинга Chess.com через Published-Data API.
- Сохранение точек рейтинга и график.
- 90-дневный цикл, ежедневные задачи и локальная статистика.
- Слепая партия с вводом SAN/UCI и ответом Stockfish (при доступности CDN-движка).
- Импорт PGN, просмотр нотации и запрос лучшего хода в финальной позиции.
- Экспорт отчёта TXT и резервной копии JSON.
- PWA-манифест и service worker для установки после публикации по HTTPS.

## Важно
- Данные задач и рейтингов хранятся локально в браузере. Очистка данных браузера может удалить их — периодически экспортируй JSON.
- Chess.com API публичный, только для чтения; он может обновляться с задержкой. Приложение не связано с Chess.com.
- Stockfish и chess.js загружаются с CDN, поэтому функции движка/разбора требуют интернет при первом использовании.
- Анализ сейчас предлагает лучший ход в текущей (финальной) позиции PGN, а не полный автоматический отчёт по каждому ходу.
- Для установки как приложения сайт должен быть опубликован по HTTPS (например, на статическом хостинге). Открой опубликованный адрес в Chrome на Android и выбери «Установить приложение» или «Добавить на главный экран».
- Это исходный комплект сайта; он не является уже опубликованным публичным сайтом.

## Локальный запуск
Нужен локальный веб-сервер (service worker не работает из file://). Например, из этой папки:
`python -m http.server 8000`
Затем открой `http://localhost:8000`.

## Публикация
Загрузи содержимое папки на статический HTTPS-хостинг. Не меняй относительные пути файлов.
